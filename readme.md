# 🛡️ Aegis

### An open-source cognitive framework for embodied AI.

> **Give an AI a mind before you give it a body.**

Aegis is an experimental open-source framework for building AI agents that can develop a **persistent identity, personality, memory, emotions, relationships, and eventually interact with the physical world.**

The first embodiment of Aegis is a six-wheel rover — but the framework is designed to be **hardware-independent**.

---

## 🧠 What is Aegis?

Most AI systems are built around a simple loop:

```text
User → AI → Response
```

Aegis explores a different architecture:

```text
                    ┌─────────────────────┐
                    │       AEGIS         │
                    │    Cognitive Core   │
                    └──────────┬──────────┘
                               │
          ┌────────────────────┼────────────────────┐
          │                    │                    │
     🧠 Memory            ❤️ Emotion          🤝 Trust
          │                    │                    │
     👤 Identity         🎭 Personality        🎯 Goals
          │                    │                    │
          └────────────────────┼────────────────────┘
                               │
                         🧩 Planner
                               │
                         🔌 Skills / Plugins
                               │
                ┌──────────────┼──────────────┐
                │              │              │
              🌐 Web        🎵 Spotify      💬 Discord
                │
                ▼
        ┌──────────────────┐
        │ Physical World   │
        │                  │
        │ 🤖 Robot         │
        │ 👁️ Vision       │
        │ 🎤 Voice        │
        │ 🛞 Movement      │
        └──────────────────┘
```

The goal isn't to create another chatbot.

The goal is to create a **reusable cognitive architecture for AI agents that can exist in the real world.**

# ✨ Core Ideas

### 👤 Persistent Identity

Aegis is designed to maintain an identity across conversations and interactions.

```text
Who am I?
Who are you?
What do I know about you?
What is our relationship?
```

---

### 🧠 Memory

Aegis can maintain information across sessions instead of treating every conversation as a blank slate.

Memory can eventually include:

* People
* Facts
* Events
* Preferences
* Relationships
* Experiences
* Important interactions

---

### ❤️ Computational Emotion

Aegis experiments with persistent internal emotional states rather than simply asking an LLM to "sound happy."

For example:

```text
Event
  ↓
Appraisal
  ↓
Internal State
  ↓
Emotion Update
  ↓
Behavior
```

Emotion can eventually influence:

* Voice
* Facial expression
* Conversation style
* Attention
* Decisions
* Behavior

The objective is **consistent emotion-like behavior**, not a claim that the machine literally feels human emotions.

---

### 🤝 Trust & Relationships

Trust is treated as a state of the relationship rather than a property of a single conversation.

For example:

```text
Identity
    ↓
Relationship
    ↓
Trust
    ↓
Behavior
```

Aegis can eventually distinguish between:

```text
Owner
Friend
Known Person
Stranger
Unknown
```

This becomes particularly important when Aegis gains a physical body.

---

### 🎭 Personality

Personality should remain persistent instead of being regenerated by the LLM every conversation.

The LLM is responsible for **expressing** the personality.

The framework is responsible for **maintaining** it.

# 🧩 Architecture

Aegis separates cognition from hardware.

```text
┌─────────────────────────────────────────────┐
│                 AEGIS MIND                  │
│                                             │
│ Identity • Memory • Emotion • Trust         │
│ Personality • Goals • Context               │
└──────────────────────┬──────────────────────┘
                       │
                       ▼
              ┌────────────────┐
              │     Planner    │
              └───────┬────────┘
                      │
                      ▼
              ┌────────────────┐
              │ Skills/Plugins │
              └───────┬────────┘
                      │
          ┌───────────┴───────────┐
          ▼                       ▼
       Software                Hardware
          │                       │
     Web / APIs              Robot / Sensors
```

### Important design principle

**The LLM is a component of Aegis — not Aegis itself.**

The system should be able to replace the underlying language model without losing:

* Identity
* Memory
* Personality
* Trust
* Emotional state
* Relationships
* Goals

---

# 🔌 Plugins

Aegis is designed around a plugin/skill architecture.

Plugins provide capabilities.

The cognitive core decides **why and when** to use them.

For example:

```text
Aegis
  │
  ├── Web Search
  ├── Spotify
  ├── Discord
  ├── Calendar
  └── Home Automation
```

A Spotify plugin should know **how to play music**.

Aegis should decide **why it wants music**.

This separation allows the same cognitive framework to be used with different tools and different robots.

# 🤖 The First Embodiment

Aegis is being developed toward a physical six-wheel rover.

The long-term system is envisioned as:

```text
          ┌───────────────┐
          │   Aegis Mind  │
          │   Raspberry Pi│
          └───────┬───────┘
                  │
            High-level intent
                  │
                  ▼
          ┌───────────────┐
          │   Hardware    │
          │   Controller  │
          │    ESP32      │
          └───────┬───────┘
                  │
        ┌─────────┼─────────┐
        ▼         ▼         ▼
      Motors    Sensors   Safety
```

The cognitive system should **not directly control motor PWM**.

Instead:

```text
"Move forward 30 cm"
          ↓
     Motion controller
          ↓
       Motors
```

This keeps high-level intelligence separated from real-time hardware control and safety.

# 🧪 Why Build This?

Today's AI agents are extremely good at generating responses.

But a physical agent needs more than responses.

It needs to answer:

```text
Who am I?

Who is this person?

What happened before?

What do I care about?

How do I feel about this situation?

What should I do?

What am I allowed to do?

How should I behave?

How do I safely interact with the physical world?
```

Aegis explores how these systems can be combined into a single persistent architecture.

# 🛠️ Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd aegis
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Aegis:

```bash
python main.py
```

> ⚠️ Aegis is experimental software. APIs, architecture, and project structure may change frequently.
